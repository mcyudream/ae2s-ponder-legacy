# AE2S Ponder Legacy 0.1.0

面向 **Minecraft 1.12.2 / Cleanroom 0.4.0 正式版（不带 -alpha）/ Java 25** 的 AE2S 思索教程附属。

## 安装与使用

安装 `ae2s-ponder-legacy-0.1.0.jar`，替换本项目旧 jar，并独立安装：

- **Applied Energistics 2 Supergiant（AE2S）1.1.0**。
- 观看教程所需的 **Ponder Legacy 1.4.0-cleanroom-alpha.1** 及 **CraftTweaker 4.1.20.698**。

悬停相关物品并按住 **W**，或运行 `/ponder index`。本附属只需安装在客户端；不安装 Ponder 时正常启动，教程入口停用。`-sources.jar` 仅供开发。

## 功能

- 八个中英文教程：第一个 ME 网络、存储元件与分区、频道与线缆、存储总线、输入/输出总线、自动合成、处理样板、ME P2P 隧道。
- 四个教程分类，支持关键帧、框选、物品移动、回退和重放。
- 使用 AE2S 的真实方块与 multipart 部件，覆盖全部颜色的五类线缆入口。
- Ponder 采用可选兼容与客户端隔离；包含正式 CR 0.4.0 物理专服的 Kirino 模组发现兼容修复。

## 验收与范围

实际安装包在正式 Cleanroom 0.4.0 上通过客户端有 Ponder **551 项**、无 Ponder **5 项**检查；两种专服组合各 **3 项**检查通过。

安装包 SHA-256：`2ab4282a0ec10c40c5eabd0e89494994e98c0a8fe5807269f6f2a0aa7a27ef6b`。CI 发布前强制核对该值及四组基线报告，附件提供 `SHA256SUMS`。

教程使用 Ponder 虚拟世界中的脚本动画；实际网络检查范围见 [正式验收记录](https://github.com/mcyudream/ae2s-ponder-legacy/blob/v0.1.0/LEGACY-VERIFICATION.md)。频道按默认配置讲解；不声明原版 AE2、AE2UEL、现代 Ponder 或任意整合包组合兼容。高级内存卡界面、多输入 P2P 和请求器尚无专门教程。
