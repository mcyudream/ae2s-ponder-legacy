# AE2S Ponder Legacy 0.3.0

- 新增驱动器、终端、元件工作台、压印器、合成／处理样板终端、样板供应器、接口共 8 套 GUI 教程。
- GUI 作为机器动画中的时间轴片段，在侧边留白弹出，与 3D 演示共用暂停、跳转与重播。
- 同一教程数据支持静态页独立演示和机器页长按 W 的实机引导；搜索框输入不被 W 打断。
- 读取 AE2S 实际语义槽位、控件与同步值，窗口调整后高亮继续对齐；不替玩家操作真实容器。
- 保持 25 篇双语图文与 24 个机器动画，补充已有教程的 GUI 环节。
- Minecraft 1.12.2 / Cleanroom 0.4.0 正式版 / Java 25；AE2S / Supergiant 1.1.0。Ponder 为可选依赖，安装时需 1.7.0 或更新版本。
