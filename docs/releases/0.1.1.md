# AE2S Ponder Legacy 0.1.1

## 修复

修复安装 **Ponder Legacy 1.4.0 正式版**时出现“必须安装正确的依赖项” / `fml.messages.version.restriction.lower.inclusive` 的启动阻断。最低版本声明改为 `after:ponder-legacy@[1.4.0,)`，保持 Ponder 可选。

## 升级

移除 `ae2s-ponder-legacy-0.1.0.jar`，安装 **`ae2s-ponder-legacy-0.1.1.jar`**；保留 **Ponder Legacy 1.4.0**。运行要求：Minecraft 1.12.2、**Cleanroom 0.4.0 正式版**、Java 25、**AE2S / Supergiant 1.1.0**，观看教程另需 CraftTweaker 4.1.20.698。只需安装在客户端。

八个中英文教程保持原有内容。悬停相关物品并按住 **W**，或运行 `/ponder index`。

## 验证

四项依赖版本回归测试通过；实际安装 jar 在正式 CR 0.4.0 上通过客户端有 Ponder **551 项**、无 Ponder **5 项**检查，两种专服组合各 **3 项**检查通过。运行报告确认实际加载的附属版本为 0.1.1、Ponder 为 1.4.0。

安装包 SHA-256：`26d132043b33f9c29e4c4af24db5f5e39cbea42a9453fe3339383a30694ef11f`。CI 发布时强制核对该值及四组验收报告，附件提供 `SHA256SUMS`。[验收记录](https://github.com/mcyudream/ae2s-ponder-legacy/blob/v0.1.1/LEGACY-VERIFICATION.md)。
