# AE2S Ponder Legacy 0.2.0

- 扩充为 25 篇中英文教程：24 个动画／图文双展示教程和 1 篇静态排障索引。
- 原有八个动画保留，新增充能器、处理器、石英生长、接口备货、库存控制、子网络、IO 端口、无线、量子桥、空间 IO、成型／湮灭面板、升级卡、合成 CPU、监视器与工具、流体存储、物质聚合器。
- 一份 Markdown 描述双展示，可按静态／动画分别补充内容；W 为唯一入口，支持游戏内 Markdown 编辑。
- 参考官方 AE2 GuideME 主题并按 **AE2S / Supergiant 1.1.0** 重写讲解与结构；无线终端采用 AE2S 的访问点配对界面。
- 可使用 Ponder 1.5.0 的结构投影、实时背包材料检查及可拖动的 HUD／背包清单，解析 AE2S 线缆与面板物品。
- Ponder 最低版本提升至 **1.5.0**，仍是可选依赖。未安装 Ponder 可正常进入世界。**无需 CraftTweaker、GuideME、FTB Quests 或 Media API**。

运行基线：Minecraft 1.12.2 / Cleanroom 0.4.0 正式版（不带 -alpha）/ Java 25。替换旧附属，观看教程请同时更新 Ponder 至 1.5.0。

生产包客户端、专服及未装 Ponder 的验收见 [正式基线记录](../../LEGACY-VERIFICATION.md)。仅声明 AE2S 1.1.0 支持；演示虚拟世界不执行完整机器配方与自动合成网络。
