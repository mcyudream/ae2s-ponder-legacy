# ME Terminal: search and transfer

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:terminal" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Search

Click the search box and enter part of an item name. While typing, W stays available as a search character; click outside before holding W for guidance.

### Network stock

The item grid shows this network's stored and craftable entries. Click a stocked item to take it; craftable entries can start a request.

### Player inventory

Transfer items between your inventory and network storage. The demonstration uses separate items and does not move your real inventory.

### Search

Clear the search to see everything again. If the terminal is offline, check power, cable connections, channels and loaded chunks.

</GuideOnly>
