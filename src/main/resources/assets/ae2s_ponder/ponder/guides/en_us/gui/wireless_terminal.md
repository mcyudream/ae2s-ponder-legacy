# Wireless Terminal

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:wireless_terminal" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Search

Search the resources exposed by this device. W remains a normal character while the field has focus.

### Stored resources

The wireless device accesses its bound network. Check the actual access point, distance and dimension when disconnected.

### Transfer and charge

Keep the device charged and test a small transfer. Portable fluid storage uses resource entries rather than treating every icon as a loose item.

### Device settings

Review supported settings before enabling automatic pickup. On a Universal Terminal, use the native terminal-type selector to switch the installed view.

</GuideOnly>
