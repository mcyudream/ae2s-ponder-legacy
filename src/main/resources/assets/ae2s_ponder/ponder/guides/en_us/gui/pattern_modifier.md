# Pattern Modifier: batch editing

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:pattern_modifier" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Editing mode

Choose the intended edit mode before selecting patterns. Batch edits can affect multiple installed recipes.

### Target patterns

Select the patterns to edit and verify their inputs and outputs. Keep a backup before replacing an established production recipe.

### Replacement and cloning

Use replacement, cloning, quantity or property controls only after checking the selected operation and blank-pattern requirements.

### Review changes

Inspect the edited patterns and test one recipe. Clear the selection when finished to avoid editing unrelated patterns next time.

</GuideOnly>
