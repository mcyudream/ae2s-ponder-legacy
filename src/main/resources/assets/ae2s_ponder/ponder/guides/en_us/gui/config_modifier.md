# Configuration Modifier: amount operations

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:config_modifier" duration={320} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Numeric operand

Enter the numeric operand used to adjust a compatible resource configuration. Inspect the original amounts before applying a bulk change.

### Arithmetic mode

Select the intended add, subtract, multiply, divide, limit, set or remove operation. A multiplication is different from setting an absolute amount.

### Numeric operand

Test one supported target and reopen its configuration. Confirm the resulting amounts before applying the tool to more devices.

</GuideOnly>
