# Requester Terminal

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:requester_terminal" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Find a requester

Search for the requester you intend to manage; naming requesters helps keep production lines separate.

### Inspect requested amounts

Review the resources and targets exposed by that requester before editing them.

### Large request lists

Scroll to review all entries and check that requests belong to the intended network and machine.

### Inspect requested amounts

If a request waits, inspect its pattern, ingredients, CPU and exact returning product in the crafting status view.

</GuideOnly>
