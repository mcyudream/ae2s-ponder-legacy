# Terminal preferences

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:terminal_settings" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Settings categories

Use the native settings pages to choose search, display, convenience and crafting preferences.

### Settings categories

Decide whether search is focused automatically and whether queries persist. Focused input keeps W available for typing.

### Settings categories

Review pickup, restock, crafting and grid-clear options before enabling them. These change real terminal behavior.

### Return and verify

Return and test the chosen settings with one item before relying on them during production.
