# Advanced Memory Card: P2P management

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:advanced_memory_card" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Find a tunnel

Search tunnel entries by the available identifying information. Give endpoints names before managing a large installation.

### Roles and frequency

Inspect each entry's type, input/output role, frequency and location before binding.

### Select the intended endpoint

Scroll to the intended endpoint and use the native bind action deliberately. Pair compatible tunnel types and keep the carrier powered.

### Roles and frequency

Test the actual remote device after binding. A saved entry is not proof that its current world position is loaded and online.

</GuideOnly>
