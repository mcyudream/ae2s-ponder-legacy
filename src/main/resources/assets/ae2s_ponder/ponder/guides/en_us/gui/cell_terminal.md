# Cell Terminal: inspect cells

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:cell_terminal" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Find a cell

Search the network cell view to locate the storage cell you intend to inspect.

### Cell overview

Inspect the displayed cell and usage information before moving or editing it. This view can represent many installed cells.

### Cell operations

Use the native view and cell controls for the selected entry. A partition filter and a real stored item are different things.

### Cell overview

After changing a cell, verify the terminal still finds its resources and the network has capacity for new inputs.

</GuideOnly>
