# Crystal Assembler

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:crystal_assembler" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Recipe input

Look up the installed Crystal Assembler recipe, then supply its input here. Do not assume a modern AE2 recipe applies unchanged.

### Supporting inventory

Check the recipe and the machine tooltip for the role of these supporting slots before automating them.

### Powered processing

Connect power and watch progress. When processing stalls, check the complete recipe, available power and output space.

### Return products

Extract only the intended product and return it to the requesting network when using a processing pattern.

</GuideOnly>
