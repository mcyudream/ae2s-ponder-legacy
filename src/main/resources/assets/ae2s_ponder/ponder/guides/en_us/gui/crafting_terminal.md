# Crafting Terminal: grid operations

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:crafting_terminal" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Find ingredients

Search the network stock. Search focus keeps W available for text entry.

### Crafting grid

Arrange the ingredients for a valid crafting recipe. This is the manual crafting grid, distinct from encoding a reusable pattern.

### Take the result

Check the result before taking it. When recipes conflict, use the available recipe-selection control.

### Clear the grid

Use the clear controls to return ingredients to storage or your inventory. Rotation and balancing controls help arrange repeated recipes.

</GuideOnly>
