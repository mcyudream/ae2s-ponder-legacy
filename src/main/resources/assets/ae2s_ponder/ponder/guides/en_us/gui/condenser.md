# Condenser: matter and singularities

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:condenser" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Consumed resources

Only feed resources you intend to consume. This machine converts supplied resources into accumulated matter.

### Output mode

Choose deletion, Matter Ball or Singularity mode as appropriate. Read the displayed requirement before feeding valuables.

### Matter capacity

Install a compatible storage component when the chosen output requires accumulated capacity.

### Collect the product

Keep the output clear. A Singularity still needs the actual entangling recipe before it can pair two quantum bridges.

</GuideOnly>
