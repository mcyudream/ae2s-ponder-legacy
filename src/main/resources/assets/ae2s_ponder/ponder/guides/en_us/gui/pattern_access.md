# Pattern Access Terminal

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:pattern_access" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Provider search

Find a provider by its name. Give providers clear names so similar machines can be distinguished.

### Ingredient search

Filter the displayed patterns by their inputs rather than only searching the provider name.

### Product search

Use output search to locate the recipe that produces a missing item. Inspect its provider before replacing a pattern.

### Manage installed patterns

The list represents actual network providers. Move or edit patterns deliberately; removing a required recipe can affect later crafting requests.

</GuideOnly>
