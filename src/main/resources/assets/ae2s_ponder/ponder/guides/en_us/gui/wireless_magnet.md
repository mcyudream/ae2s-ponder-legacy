# Wireless magnet settings

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:wireless_magnet" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Pickup rules

Select which dropped resources may be picked up. Keep the pickup filter narrow while testing.

### Insertion rules

Configure which collected resources may be inserted into ME storage. Pickup and insertion are separate decisions.

### Matching modes

Check pickup mode, insertion mode and the master switch before enabling automatic collection.

### Enable and test

Test with one drop and verify the destination, wireless connection, power and available network capacity.

</GuideOnly>
