# Quantum Bridge: pair the ends

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:quantum_bridge" duration={320} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Entangled pair

Place one member of the same entangled pair into each completed bridge. An ordinary Singularity is not an already paired entangled item.

### Power and formation

Check the full ring structure and power on both ends. Merely inserting the pair does not repair an incomplete structure.

### Entangled pair

Keep relevant chunks loaded and test the intended remote device. Removing the paired item disconnects the link.

</GuideOnly>
