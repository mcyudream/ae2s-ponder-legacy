# Cell Workbench: configure a partition

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:cell_workbench" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Cell to configure

Insert the storage cell you want to configure. Read its current contents before changing restrictions.

### Partition filter

Set the item filters in the configuration grid. These are ghost entries; they select allowed types and do not supply stored items.

### Partition filter

Use supported cell upgrades only when needed. Page buttons appear for cells with more filter entries; live highlights follow the visible slots.

### Cell to configure

Remove the configured cell and put it back into the drive. Confirm that allowed items enter it and other types use a different cell.

</GuideOnly>
