# ME Drive: insert storage

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:drive" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Storage cell slot

Insert an ME storage cell. The drive needs network power and a channel before the terminal can use it.

### Additional cell

The ten slots hold independent cells. Add a larger cell when bytes or available types run short.

### Storage cell slot

Cell contents stay on the cell when you remove it. Keep a backup before reorganizing your storage.

### Storage cell slot

Close this window and open the ME Terminal to test insertion and extraction. A drive is not a direct item input.

</GuideOnly>
