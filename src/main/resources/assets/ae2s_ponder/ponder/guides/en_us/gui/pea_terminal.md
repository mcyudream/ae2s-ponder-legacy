# Pattern Encoding Access Terminal

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:pea_terminal" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Find the destination

Locate a destination provider in the access list before uploading a new pattern.

### Recipe input filter

Combine provider, input and output searches to narrow a large network to the relevant recipes.

### Encoding mode

Choose crafting or processing as required. Reusable machine tools must not be listed as consumed processing ingredients.

### Encode and verify

Verify the blank pattern, recipe, amounts and output before encoding. Use the upload control only after confirming the destination.

</GuideOnly>
