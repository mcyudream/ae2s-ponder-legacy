# Molecular Assembler

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:molecular_assembler" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Crafting patterns

Use crafting patterns for crafting-grid recipes. Processing patterns belong to machines that perform the described process.

### Acceleration

Install supported acceleration upgrades after a single recipe works. Parallel demand also depends on the available crafting CPUs and ingredient supply.

### Crafting patterns

A neighboring Pattern Provider can send crafting work to an assembler. Check adjacency and network power when a job waits.

### Duplicate recipes

If several devices offer the same recipe, inspect their priority and availability before scaling the setup.

</GuideOnly>
