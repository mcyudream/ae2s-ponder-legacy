# Wireless Access Point: pair a device

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:wireless_access_point" duration={324} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Device to pair

Insert a supported wireless device into the pairing input. This associates the device with this network access point.

### Paired device

Collect the paired device from the output. Keep it charged before trying remote access.

### Wireless range

Read the actual range and energy use. Supported booster slots can change the tradeoff between range and power cost.

### Boosters and testing

Use compatible boosters, then test access from the intended location and dimension. Do not assume every wireless feature bypasses range.

</GuideOnly>
