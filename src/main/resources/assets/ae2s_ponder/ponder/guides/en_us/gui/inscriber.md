# Inscriber: print a silicon circuit

## Find the device

Open the named AE2S device or the related subdialog. The structure shows the surrounding network context; use the GUI demonstration to inspect its controls.

## GUI operation

Follow the cursor, highlighted controls and resource entries in the demonstration. Playback uses separate data.

<GuiTutorial id="ae2s_ponder:inscriber" duration={400} side="right" />

## Follow along in game

On the actual device, leave the text field and hold W to start guidance. Perform native operations yourself; the guide observes controls and does not send machine actions.

## Verify the result

Check the real inventory, selected settings and destination. Start with one transfer or one batch before scaling up.

<GuideOnly>

### Upper press slot

Put the Silicon Press in the upper press slot. Leave the lower slot empty for this printing recipe; the press is reusable.

### Input material

Insert silicon into the middle input. Check the installed recipe viewer if your pack changes the material.

### Processing progress

Supply power and wait for real machine progress. The live guide observes synchronized progress or a completed output, including fast upgraded machines.

### Printed result

The Printed Silicon appears in the output. Combine it with a printed circuit and redstone in a separate assembly operation.

### Printed result

Collect the result while leaving the press installed. For automation, verify each accessible machine face with one test item.

</GuideOnly>
