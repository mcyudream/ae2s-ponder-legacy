# 样板管理终端

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:pattern_access" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 供应器搜索

按名称查找供应器，建议为供应器命名，以区分用途相近的机器。

### 输入搜索

可按样板输入过滤显示结果，不必只搜索供应器名称。

### 产出搜索

按产物查找缺少物品的配方，替换样板前先确认所属供应器。

### 管理已安装样板

列表对应网络中的实际供应器；移动或编辑样板前确认用途，删除配方会影响后续合成请求。

</GuideOnly>
