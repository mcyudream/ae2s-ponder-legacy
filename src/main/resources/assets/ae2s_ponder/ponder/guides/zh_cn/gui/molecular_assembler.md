# 分子装配室

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:molecular_assembler" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 合成样板

合成网格配方应使用合成样板，处理样板用于执行对应加工过程的机器。

### 加速升级

单个配方跑通后再安装支持的加速升级，并行需求也受合成 CPU 与原料供应限制。

### 合成样板

相邻样板供应器可向装配室发送合成任务，任务等待时检查邻接关系和供电。

### 重复配方

多个设备提供同一配方时，扩建前先核对它们的优先级与可用状态。

</GuideOnly>
