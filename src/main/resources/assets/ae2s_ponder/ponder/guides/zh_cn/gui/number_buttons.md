# 数值输入快捷设置

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:number_buttons" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 普通增量

使用原生数值输入框配置普通增减按钮。

### 修饰键增量

分别检查 Shift、Ctrl 与 Alt 增量，避免修饰键点击意外请求大量物品。

### 测试结果

返回数量窗口，用小数值验证后再提交实际操作。

</GuideOnly>
