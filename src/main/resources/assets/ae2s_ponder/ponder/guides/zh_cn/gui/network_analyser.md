# 网络分析仪

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:network_analyser" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 分析模式

选择预期显示模式，检查它正在分类的节点或连接。

### 节点统计

比较普通、致密与缺失节点统计，这些标签描述当前分析结果，不会自动修复网络。

### 显示颜色

设置容易区分的颜色，再在世界中对照显示寻找相应线缆和设备。

</GuideOnly>
