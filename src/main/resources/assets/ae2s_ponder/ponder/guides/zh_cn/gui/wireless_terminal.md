# 无线终端

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:wireless_terminal" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 搜索

搜索此设备公开的资源，输入框获得焦点时，W 保持作为普通字符。

### 存储资源

无线设备访问已绑定网络，断开时检查访问点、距离与维度。

### 转移与充能

保持设备电量并测试少量转移，便携流体存储使用资源条目，不应把所有图标理解为散装物品。

### 设备设置

启用自动拾取前先检查设置。通用终端可通过原生终端类型选择器，切换已安装的终端视图。

</GuideOnly>
