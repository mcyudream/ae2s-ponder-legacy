# 样板修改器：批量编辑

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:pattern_modifier" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 编辑模式

选择目标样板前先确定编辑模式，批量修改可能影响多个已安装配方。

### 目标样板

选择待修改样板并核对输入与输出，替换已有生产配方前先备份。

### 替换与复制

使用替换、复制、数量与属性操作前，核对当前操作与空白样板需求。

### 检查修改

检查修改后的样板并测试一个配方，结束后清理选择，避免下次误改无关样板。

</GuideOnly>
