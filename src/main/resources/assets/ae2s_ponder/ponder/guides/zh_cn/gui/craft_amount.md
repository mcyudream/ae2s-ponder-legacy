# 发起合成：数量

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:craft_amount" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 请求数量

输入目标数量并核对显示单位，这只是请求，不代表网络已经备齐材料。

### 计算计划

继续计算配方计划，大额任务开始前应阅读材料与 CPU 检查。

### 数量快捷键

按需设置数量增减快捷键，注意修饰键下的增量与最终请求数量不同。

</GuideOnly>
