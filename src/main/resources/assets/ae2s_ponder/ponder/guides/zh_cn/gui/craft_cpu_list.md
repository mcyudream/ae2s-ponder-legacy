# 合成 CPU 选择

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:craft_cpu_list" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 查找 CPU

搜索已命名的合成 CPU，选择预期生产线。

### 比较 CPU

排序并检查空闲状态与存储容量，空闲 CPU 的容量必须满足当前计划。

### 选择目标

选择合适条目后返回，并核对确认页面显示的 CPU。

</GuideOnly>
