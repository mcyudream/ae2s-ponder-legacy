# 配置修改器：数量运算

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:config_modifier" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 运算数值

输入调整兼容资源配置所用的数值，批量修改前先检查原有数量。

### 运算模式

选择所需的加、减、乘、除、限制、设定或移除操作；乘法与设为固定数量不同。

### 运算数值

先对一个支持的目标测试并重新查看配置，确认数量结果后再用于更多设备。

</GuideOnly>
