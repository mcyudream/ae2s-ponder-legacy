# 样板终端：处理样板

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:pattern_processing" duration={400} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 处理模式

选择处理模式，用于外部机器的加工配方。

### 空白样板

放入空白样板。实机引导只观察真实槽位，不会替你放入物品。

### 消耗的原料

填写准确的输入、输出和数量。留在机器内重复使用的模板，不应列为每次消耗的原料。

### 编码

核对模式、原料与产物后点击编码。编码仍需有效配方与空白样板。

### 已编码样板

取出已编码样板，装入样板供应器。处理产物必须回到发起任务的同一网络。

</GuideOnly>
