# 存储优先级

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:priority" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 优先级数值

设置优先级并阅读存入与取出提示，优先级不会增加容量。

### 存入顺序

按页面显示的存入规则，确定新资源应优先进入哪个存储。

### 取出顺序

单独核对取出规则，重整整个网络前先测试一种资源。

</GuideOnly>
