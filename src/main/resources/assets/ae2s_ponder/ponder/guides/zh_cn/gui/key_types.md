# 选择资源类型

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:key_types" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 资源类型选择

选择要显示或处理的资源类型，例如物品或流体；可用类型取决于已安装联动。

### 核对视图

返回后确认过滤视图仍包含所需资源，隐藏类型不代表删除库存。

</GuideOnly>
