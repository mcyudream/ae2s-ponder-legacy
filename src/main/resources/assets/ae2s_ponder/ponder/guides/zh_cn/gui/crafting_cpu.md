# 合成 CPU：运行任务

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:crafting_cpu" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 跟踪产物

搜索运行任务，找到当前所需或正在制作的资源。

### 阅读任务进度

区分已存原料、正在加工的内容与预期回网产物；处理任务可能正在等待特定产物。

### 暂停任务

暂停生产前核对暂停控件及其状态，暂停不会撤回已经投送给机器的物品。

### 取消任务

仅在确认需要时取消，重新提交任务前先检查机器与中间产物。

</GuideOnly>
