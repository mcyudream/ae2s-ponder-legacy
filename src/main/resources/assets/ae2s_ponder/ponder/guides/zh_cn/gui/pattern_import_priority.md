# 配方导入优先级

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:pattern_import_priority" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 优先配方来源

排列导入配方时优先使用的来源，这一顺序针对配方选择，不是存储优先级。

### 检查全部页面

确认顺序前检查全部条目，可选配方来源取决于已安装配方联动。

### 验证导入

返回编码页面，导入一个配方并核对原料与产物。

</GuideOnly>
