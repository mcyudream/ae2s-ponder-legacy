# 网络工具：升级与诊断

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:network_tool" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 升级卡收纳

可在工具库存内收纳兼容升级卡，槽内存放的是真实物品。

### 检查目标网络

对预期网络设备使用工具检查实际状态，并确认当前检查的是哪个网络。

### 升级卡收纳

为取出的升级卡留出空间，改变升级后重新检查机器设置。

</GuideOnly>
