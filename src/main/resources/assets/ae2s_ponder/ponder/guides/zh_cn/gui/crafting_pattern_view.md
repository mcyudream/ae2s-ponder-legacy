# 查看合成样板

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:crafting_pattern_view" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 已记录配方

检查样板记录的合成网格与产物，此页面描述配方，不会制作物品。

### 替代设置

先阅读物品与流体替代设置，不要直接假定相近原料能够互换。

### 已记录配方

将目标样板安装到正确供应器或装配室，再测试一次请求。

</GuideOnly>
