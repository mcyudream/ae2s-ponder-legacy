# 合成依赖树

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:crafting_tree" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 配方分支

从请求产物向下跟踪原料及中间合成分支。

### 缺失分支

使用仅显示缺失分支的过滤，集中查看阻碍计划的资源与依赖。

### 导出视图

原生截图按钮可导出合成树，引导不会替你执行文件导出。

### 返回计划

定位缺失依赖后，返回父分支或合成计划。

</GuideOnly>
