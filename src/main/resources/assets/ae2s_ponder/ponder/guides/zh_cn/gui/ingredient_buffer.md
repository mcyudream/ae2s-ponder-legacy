# ME 原料缓存器

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:ingredient_buffer" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 原料库存

将原料缓存器作为原料投送与加工机器之间的中转库存。

### 核对批量

用一批原料核对邻接侧面的存取方式；缓存器不能修正错误的样板配方。

### 原料库存

将产物回收与原料投送分开，让合成 CPU 能收到预期产物。

</GuideOnly>
