# 虚空存储元件：处理模式

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:void_cell" duration={320} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 资源处理模式

仔细阅读销毁或物质转换模式，已接受销毁的资源不能当作可取回的普通库存。

### 限制输入范围

接入主存储前，限制能够到达此设备的资源，并用可消耗物品测试。

### 产物与容量

产出物质产物时，为其留出空间，并核对实际转换要求。

</GuideOnly>
