# 高级内存卡：P2P 管理

## 找到设备

打开对应 AE2S 设备或相关子页面。结构展示其网络上下文，使用 GUI 演示查看控件与操作。

## 界面操作

跟随演示中的光标、高亮控件与资源条目。回放使用独立数据。

<GuiTutorial id="ae2s_ponder:advanced_memory_card" duration={324} side="right" />

## 实机跟随

在真实设备中，离开输入框后长按 W 进入引导。原生操作仍由你执行，引导观察控件，不会代发机器操作。

## 核对结果

检查真实库存、所选设置与目标去向。扩大规模前，先测试一次传输或一批加工。

<GuideOnly>

### 查找隧道

按可用标识搜索隧道条目，大规模管理前先为端点命名。

### 角色与频率

绑定前核对条目类型、输入输出角色、频率与位置。

### 选择正确端点

滚动到目标端点，再主动执行原生绑定操作；配对兼容类型并为承载网络供能。

### 角色与频率

绑定后测试真实远端设备，保存的条目不代表其当前位置已经加载且在线。

</GuideOnly>
